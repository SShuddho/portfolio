# Safius Sakib Shuddho – Academic Portfolio

This repository contains the source code for my academic portfolio website, built with Jekyll and hosted using GitHub Pages.

## Website

https://sshuddho.github.io/portfolio/

## About

The website presents my academic profile and research activities, including:

- Education
- Research interests
- Publications
- Projects
- Certifications
- Leadership and extracurricular activities
- Languages
- Self-study and online courses

## Technologies

- Jekyll
- HTML5
- CSS3
- Bootstrap 5
- GitHub Pages

## Local Development

Clone the repository and install dependencies:

```bash
bundle install
```

Serve the site locally:

```bash
bundle exec jekyll serve
```

The site will be available at:

```
http://localhost:4000
```
